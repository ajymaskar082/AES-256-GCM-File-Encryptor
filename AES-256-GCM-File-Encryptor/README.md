# AES-256-GCM File Encryptor

## Жобаның мақсаты

Бұл жобаның мақсаты — файлдарды AES-256-GCM алгоритмі арқылы қауіпсіз шифрлау және қажет болған жағдайда бастапқы қалпына келтіру.

Бағдарлама пайдаланушы енгізген құпиясөз негізінде криптографиялық кілт жасайды. Файлдар кездейсоқ Salt және IV мәндерін пайдалану арқылы шифрланады.

## Қолданылатын технологиялар

- Java 17
- Apache Maven
- JUnit 5
- Java Cryptography Architecture (JCA)
- javax.crypto
- SecureRandom
- PBKDF2WithHmacSHA256

## Негізгі мүмкіндіктері

- Құпиясөз арқылы шифрлау кілтін жасау.
- AES-256-GCM алгоритмімен файлдарды шифрлау.
- Шифрланған файлды бастапқы қалпына келтіру.
- Әр шифрлау кезінде кездейсоқ Salt және IV пайдалану.
- Үлкен файлдарды бөліктермен өңдеу.
- Қате құпиясөз бен бұзылған файлдарды анықтау.
- Шифрланған деректердің тұтастығын тексеру.

## Қолданылатын криптографиялық әдістер

- **AES-256** — 256 биттік шифрлау кілтін қолданады.
- **GCM** — деректердің құпиялылығы мен тұтастығын қамтамасыз етеді.
- **PBKDF2WithHmacSHA256** — құпиясөзден криптографиялық кілт алады.
- **SecureRandom** — кездейсоқ Salt және IV генерациялайды.

## Шифрланған файлдың құрылымы

Шифрланған файл келесі бөліктерден тұрады:

1. MAGIC — файл форматын анықтайтын белгі.
2. Salt — кілт жасау үшін қолданылатын кездейсоқ мән.
3. IV — AES-GCM алгоритмінің бастапқы векторы.
4. Encrypted Data — шифрланған деректер және аутентификация тегі.

## Орнату

Жобаны GitHub репозиторийінен жүктеп алып, IntelliJ IDEA арқылы ашыңыз.

Maven көмегімен жобаны құрастыру:

```bash
mvn clean package
```

## Қолдану

Бағдарламаны `Main` класынан іске қосыңыз.

Бағдарламада келесі әрекеттер орындалады:

1. 1 — файлды шифрлау.
2. 2 — файлды дешифрлау.
3. Кіріс файлдың жолын енгізу.
4. Шығыс файлдың жолын енгізу.
5. Құпиясөзді енгізу.

Дешифрлау кезінде шифрлау барысында қолданылған құпиясөзді пайдалану қажет.

## Тестілеу

Тесттерді іске қосу:

```bash
mvn clean test
```

Жоба JUnit 5 көмегімен 15 тест арқылы тексерілді.

Тесттер мыналарды қамтиды:

- Кіші және үлкен файлдарды шифрлау және дешифрлау.
- Бос файлды өңдеу.
- Қате құпиясөзді анықтау.
- Бұзылған шифрланған файлды анықтау.
- Қате файл жолдарын тексеру.
- Salt және IV мәндерінің әр шифрлауда өзгеруін тексеру.

**Тестілеу нәтижесі:** 15 тест орындалды, 0 қате, 0 сәтсіздік.

## Қауіпсіздік туралы ескерту

- Құпиясөзді басқа адамдарға бермеңіз.
- Құпиясөзді жоғалтсаңыз, файлды қалпына келтіру мүмкін болмайды.
- Salt пен IV әр шифрлау кезінде кездейсоқ жасалуы керек.
- Құпия кілттер мен құпия деректерді GitHub-қа жүктемеңіз.
- AES-GCM деректердің тұтастығын тексереді.
